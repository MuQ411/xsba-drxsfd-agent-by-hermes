# 中文法律数据库查询 Skill

## Overview

让 Hermes Agent 能够有效查询中文法律数据库，包括法律法规、司法解释、裁判文书、法学论文等。本 Skill 指导 Agent 使用已有的 web_search、web_extract、browser 工具访问各类法律资源。

## When to Use

- 用户询问具体法律法规条文
- 用户需要查找相关司法解释
- 用户需要检索同类案例（类案检索）
- 用户询问法律概念、构成要件、罪名界分
- 用户进行案例分析需要法律依据支撑
- 用户提到「查一下XX法」「有没有相关案例」「XX罪的量刑标准」

## 法律信息验证原则

查询到法律信息后，必须进行以下验证：

1. **时效性验证**: 确认法条是否为现行有效版本（注意民法典取代了婚姻法、继承法、合同法等；刑法修正案十一/十二的修改）
2. **效力层级**: 法律 > 行政法规 > 地方性法规 > 司法解释 > 部门规章
3. **来源可信度**: 优先使用 .gov.cn 官方来源，其次为北大法宝等权威数据库
4. **法条引证格式**: 引用时使用标准格式，如「《中华人民共和国刑法》第二百三十二条」
5. **重要提示**: 2021年1月1日起《民法典》施行，婚姻法、继承法、民法通则、收养法、担保法、合同法、物权法、侵权责任法、民法总则同时废止

## Common Pitfalls

1. **不要假设法条未修改**: 刑法经过11次修正（最新为修正案十二，2024年3月1日施行），查询前先确认现行有效版本
2. **不要混淆司法解释和法律的效力**: 司法解释是对法律的具体适用解释，不能创设新的罪名
3. **注意裁判文书的时效**: 老案例可能基于已被修改的法律，需确认法条现行状态
4. **类案检索时注意案由、审级、地域差异**: 不同地区法院量刑标准可能不同
5. **不要仅依赖 AI 的法条记忆**: 大型语言模型可能产生幻觉，关键法条必须验证

## 刑法案例分析工作流

当用户提出刑法案例分析需求时，按以下步骤操作：

1. **检索相关法条**: 优先使用 `web_search site:drxsfd.com` 查法条原文和关联司法解释；同时用 `web_search site:xsba.vip` 查罪名评释
2. **检索类案**: `web_search site:xsba.vip` 查询类似案例（含刑事审判参考、人民司法案例等）
3. **检索量刑标准**: `web_search site:xsba.vip` 查量刑指导原则和方法；查地方规定中的量刑标准
4. **检索理论**: `web_search` 查询相关刑法理论（如罪过形态、因果关系、违法性认识等）
5. **综合分析**: 结合法条、案例、量刑标准、理论给出鉴定式分析

**推荐优先使用 xsba.vip 和 drxsfd.com**，因为这两个站点由一线办案检察官维护，内容更贴近实务，更新更及时，且无付费墙。
