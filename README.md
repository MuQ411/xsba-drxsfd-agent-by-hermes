# xsba-drxsfd-agent-by-hermes

Hermes Agent skill for Chinese criminal law research using xsba.vip and drxsfd.com.

## 内容

- `skills/legal-research.md` — legal-research 技能，包含：
  - **xsba.vip**（刑事司法办案业务资料汇编）完整路径速查表
  - **drxsfd.com**（东人刑事法典）完整 bh 编号速查表（200+ 条）
  - 刑法案例分析工作流
  - GB2312 站点抓取技术说明

## 使用

将 `skills/legal-research.md` 复制到 Hermes 的 skills 目录即可：

```bash
cp skills/legal-research.md ~/.hermes/skills/legal-research/SKILL.md
```

## 两个站点

| 站点 | URL | 定位 |
|------|-----|------|
| xsba.vip | http://xsba.vip/ | 刑事办案实务资料汇编（案例、量刑、司法观点） |
| drxsfd.com | http://www.drxsfd.com/ | 东人刑事法典（法条+司法解释关联查询） |
